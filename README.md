Hub de Aulas — Flexbox e Grid

Site educativo sobre CSS para a disciplina de IHC, com explicações, exemplos e atividades práticas.

Site: https://marcioeduardo11.github.io/trabalho-dionatam/

Páginas
index.html: Hub com os cards dos módulos.
flexbox.html: Conceitos, propriedades e exemplos de Flexbox.
grid.html: Conceitos, propriedades e exemplos de Grid.
hub.css: Estilos compartilhados.
flexbox.css e grid.css: Estilos específicos.
aprenda.js: Playgrounds e testes de CSS.
Estrutura das páginas
Conceitos básicos.
Tabela de propriedades.
Exemplos visuais com código.
Playground interativo.
Exercícios práticos.
Área para testar CSS.
Conteúdo

Flexbox: organização de itens, alinhamento, espaçamento, direção e responsividade.

Grid: organização em linhas e colunas, áreas nomeadas, espaçamento e layouts responsivos.

Acessibilidade

HTML semântico, foco visível, bom contraste, navegação por teclado e layout responsivo.

Integrantes

Cada integrante deve realizar sua parte e enviar commits para o repositório.

Publicação

O projeto é publicado pelo GitHub Pages, usando a branch main e a pasta raiz (/). Após a publicação, todos os links devem ser testados.

Integração com o hub do professor

Copiar os arquivos flexbox.html, grid.html, hub.css, flexbox.css, grid.css e aprenda.js, sem substituir os arquivos originais do professor.
