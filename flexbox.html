Flexbox

Layout unidimensional: organiza os itens em uma linha ou em uma coluna, distribuindo o espaço entre eles.

1. O que é Flexbox?

O Flexbox (Flexible Box Layout) é um modelo de layout do CSS pensado para alinhar e distribuir espaço entre itens em uma única direção. Basta declarar display: flex no elemento pai (o container); os filhos diretos viram flex items.

.container {
  display: flex;
}

Os dois eixos

Todo container flex tem dois eixos. Entender isso é a chave do Flexbox:

  • Eixo principal (main axis): direção em que os itens fluem. Por padrão é horizontal (row).
  • Eixo transversal (cross axis): perpendicular ao principal. Por padrão é vertical.

Regra de ouro: justify-content alinha no eixo principal; align-items alinha no eixo transversal. Se você trocar para flex-direction: column, os eixos também trocam de lugar.

2. Conceitos básicos (propriedades do container)

Propriedades aplicadas no pai
PropriedadeO que fazValores comuns
displayAtiva o Flexbox no container.flex, inline-flex
flex-directionDefine a direção do eixo principal.row, row-reverse, column, column-reverse
justify-contentDistribui os itens no eixo principal.flex-start, center, flex-end, space-between, space-around, space-evenly
align-itemsAlinha os itens no eixo transversal.stretch, flex-start, center, flex-end, baseline
flex-wrapPermite quebrar para outra linha quando falta espaço.nowrap, wrap, wrap-reverse
gapEspaço entre os itens (sem usar margin).0, 8px, 1rem…

3. Conceitos intermediários (propriedades dos itens)

Além do container, cada item pode ter regras próprias. É aqui que o Flexbox fica poderoso.

Propriedades aplicadas nos filhos
PropriedadeO que faz
flex-growQuanto o item cresce para ocupar o espaço que sobrou (proporção). Padrão: 0.
flex-shrinkQuanto o item encolhe quando falta espaço. Padrão: 1.
flex-basisTamanho inicial do item no eixo principal, antes de crescer ou encolher. Padrão: auto.
flexAtalho: flex: grow shrink basis. Ex.: flex: 1 equivale a 1 1 0.
align-selfSobrescreve o align-items só para este item.
orderMuda a ordem visual sem mexer no HTML. Padrão: 0.

flex-grow: dividindo o espaço que sobra

.item:nth-child(1) { flex: 0 0 auto; }
.item:nth-child(2) { flex: 1; }
.item:nth-child(3) { flex: 2; }

flex-basis e wrap: itens que se adaptam

.item {
  flex: 1 1 140px;
  /* cresce | encolhe | tamanho base */
}

order e align-self: controle individual

.item:nth-child(1) { order: 3; }
.item:nth-child(2) { order: 1; align-self: flex-end; }
.item:nth-child(3) { order: 2; align-self: center; }

Atenção à acessibilidade: order muda só o visual. Leitores de tela e a tecla Tab continuam seguindo a ordem do HTML. Use com cuidado.

margin: auto — o truque do espaço

.item:last-child {
  margin-left: auto;
}

4. Aplicações reais

Estes quatro padrões resolvem a maior parte dos layouts do dia a dia.

a) Barra de navegação

.barra {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
.barra ul {
  display: flex;
  gap: 1rem;
}

b) Centralizar no meio (horizontal e vertical)

.caixa {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 9rem;
}

c) Cards que quebram de linha

.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 0.75rem;
}
.cards .card {
  flex: 1 1 110px;
}

d) Rodapé sempre no fim da página

body {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}
footer {
  margin-top: auto;
}

5. Atividade prática

  1. Crie 4 caixas dentro de um container e coloque-as lado a lado com display: flex.
  2. Use justify-content: space-between e depois center. O que muda?
  3. Troque para flex-direction: column. Quais eixos mudaram de papel?
  4. Dê flex: 1 a todas as caixas e depois flex: 2 a uma delas.
  5. Monte uma barra de navegação com logo à esquerda e links à direita.
  6. Desafio: centralize uma caixa no meio da tela (horizontal e vertical).
