Grid

1. O que é Grid?

O CSS Grid cria uma grade no elemento pai (grid container). Os filhos diretos (grid items) são colocados nas células dessa grade, que é formada por linhas e colunas.

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 0.5rem;
}

Vocabulário

  • Trilha (track): uma coluna ou uma linha da grade.
  • Célula: o encontro de uma linha com uma coluna (como uma célula de tabela).
  • Linhas de grade (grid lines): as divisórias numeradas, começando em 1. Uma grade com 3 colunas tem 4 linhas verticais.
  • Área: conjunto de células vizinhas ocupado por um item.
  • gap: o espaço entre as trilhas.

2. Dividindo em linhas e colunas

Propriedades do container
PropriedadeO que faz
display: gridAtiva o Grid.
grid-template-columnsDefine quantas colunas existem e a largura de cada uma.
grid-template-rowsDefine a altura das linhas. Linhas extras ficam com altura automática.
gap (row-gap, column-gap)Espaço entre linhas e colunas.
justify-itemsAlinha o item horizontalmente dentro da célula.
align-itemsAlinha o item verticalmente dentro da célula.

Unidades das trilhas

  • px, rem, %: tamanhos fixos ou proporcionais ao pai.
  • fr (fração): divide o espaço livre. 1fr 2fr dá ao 2º o dobro do 1º.
  • auto: ajusta ao conteúdo.
  • repeat(3, 1fr): atalho para 1fr 1fr 1fr.
  • minmax(100px, 1fr): nunca menor que 100px, nunca maior que 1 fração.
.container {
  display: grid;
  grid-template-columns: 110px 1fr 2fr;
}
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: 3rem 6rem;
  gap: 0.5rem;
}

3. Posicionando itens nas linhas e colunas

Cada item pode ocupar mais de uma célula. Para isso usamos os números das linhas de grade:

Propriedades dos itens
PropriedadeExemploSignificado
grid-column1 / 3Começa na linha 1 e termina na linha 3 (ocupa 2 colunas).
grid-columnspan 2Ocupa 2 colunas a partir de onde estiver.
grid-row1 / 3Ocupa as linhas 1 e 2.
justify-self / align-selfcenterAlinha só este item dentro da célula.
 
.destaque {
  grid-column: 1 / 3;
  grid-row: 1 / 3;
}
.largo {
  grid-column: span 2;
}

Alinhamento dentro das células

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  justify-items: center;
  align-items: center;
}
/* atalho para os dois: place-items: center; */

4. Áreas nomeadas: desenhando o layout em texto

Com grid-template-areas você "desenha" a página usando nomes. Cada linha de texto é uma linha da grade, e repetir um nome faz a área se estender.

.pagina {
  display: grid;
  grid-template-areas:
    "cabecalho cabecalho"
    "menu      conteudo"
    "rodape    rodape";
  grid-template-columns: 110px 1fr;
}
.a-cabecalho { grid-area: cabecalho; }
.a-menu      { grid-area: menu; }
.a-conteudo  { grid-area: conteudo; }
.a-rodape    { grid-area: rodape; }

Dica de responsividade: no celular, basta redefinir o grid-template-areas em uma @media com uma área por linha, e o layout empilha sem mexer no HTML.

5. Grid responsivo sem media query

A combinação repeat(auto-fit, minmax(...)) faz a grade decidir sozinha quantas colunas cabem.

.container {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(110px, 1fr));
  gap: 0.5rem;
}

Leitura: "crie quantas colunas de no mínimo 110px couberem; o espaço que sobrar é dividido igualmente entre elas".

6. Grid ou Flexbox?

FlexboxGrid
DimensõesUma (linha ou coluna)Duas (linhas e colunas)
Quem manda no layoutO conteúdo dos itensA grade definida no container
Bom paraBarras de menu, alinhamentos, grupos de botõesPáginas inteiras, galerias, painéis

Eles se complementam: é comum usar Grid para a estrutura da página e Flexbox para alinhar o conteúdo dentro de cada área.

7. Atividade prática

  1. Crie uma grade com 3 colunas iguais e 6 itens usando repeat(3, 1fr).
  2. Mude para 200px 1fr 2fr e observe como o espaço é dividido.
  3. Faça o primeiro item ocupar 2 colunas com grid-column: span 2.
  4. Monte um layout de página com cabeçalho, menu lateral, conteúdo e rodapé usando grid-template-areas.
  5. Torne a galeria responsiva com auto-fit e minmax(150px, 1fr).
  6. Desafio: no layout do item 4, use Flexbox para alinhar o conteúdo do cabeçalho.
